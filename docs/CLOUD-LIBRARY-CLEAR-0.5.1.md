# 0.5.1：刪除玩家本機的雲端譯本

設定 → 雲端同步 → X「刪除本機譯本」，再按一次「確認刪除」。會刪除繁簡譯本（含待啟用及舊版本），並停用全域與所有存檔的自動下載。未套用的其他設定不會被儲存。刪除不會修改 Cloudflare 公共譯庫，也不會刪除內建字典、使用者校正、AI 主快取、API 金鑰或存檔。

遊戲已載入的譯本會保留在目前程序的部分顯示快取中，請關閉並重新開啟遊戲。保留下來的內建字典及個人 AI 快取仍會顯示中文，因此此功能不是「把所有中文翻譯歸零」。若要重新取得雲端譯本，使用「立即同步」，或重新開啟自動下載並套用；遊戲中下载仍按既有規則於下次啟動採用。

刪除與下載共用序列化邊界，等待執行中的下載完成後刪除，並作廢已排隊的下載。刪除中不接受新下載。設定信箱為此作業保留最多 130 秒等待時間，涵蓋既有下載重試與回覆交接。重新啟用自動下載會重置本機的六小時檢查節流。

保留已驗證簽章清單和最高版本序號，但清空 active/pending/previous 的套件指標與內容。同一份已簽章清單可以重新下載，更新的序號也可正常升級；舊版及相同序號的衝突清單仍拒收。模組版本恢復遞增為 0.5.1，與雲端譯庫的發布序號獨立。
