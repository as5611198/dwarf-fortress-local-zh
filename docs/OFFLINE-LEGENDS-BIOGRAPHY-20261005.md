# Verified Legends biography subjects

The prior cold development run left complete introductory biographies in English.
The reader now resolves the figure's authoritative English name once when a new
historical-figure page is captured. An exact, complete unlinked prefix ending
immediately before ` was ` becomes a local-only DFT text slot. Later paragraphs,
partial names, invalid UTF-8/controls/markup, and clickable spans are excluded.
The original source, native words, links and palette boundaries remain intact.
Failed name reads are logged and retain native prose. No names are added to the
shipped dictionaries or exported as new click identities.

The shared Native/Broker composer handles reviewed typed races, optional birth
years, son/daughter birth order and linked parents, and unique-kind descriptions.
It supports the observed wealth/fire association clause with a finite vocabulary.
Unknown species, spheres, malformed dates, inconsistent gender pronouns, missing
parents and trailing clauses reject the complete biography. Existing fixed event
templates retain precedence; a regression caught and prevented blocking cave
descriptions. The local DFT slots remain forbidden in rich network requests and
response journals.

implementation. The ordinary workspace passed 110 Broker and 91 Native unit tests,
plus the other workspace/integration suites; opt-in tests remain separate. Eight
relevant Node tests and six packaged Lua fixtures passed. Both packaged Native
and empty-state Broker passed 74 exact bilingual checks: 64 accepted translations
and 10 atomic rejections, with zero worker/provider submissions. Workshop validation
and all 913 manifest file hashes passed. Both binaries use a static CRT build.
