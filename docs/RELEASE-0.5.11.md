# 0.5.11：繁簡離線翻譯擴充與穩定性修正

這次先發布已驗證的離線擴充與修補。目標仍是讓大多數原版內容不必等待 AI；目前尚未完成要塞、冒險、傳說三模式的獨立覆蓋率驗收，**不能宣稱原版整體已有 90% 無 AI 覆蓋率**。已支援的內建字典與規則可在關閉 AI、沒有 API Key 時使用；未知內容保留原文，啟用 AI 後可繼續補譯。

## 本次更新

- 擴充人物性格、價值觀引言、外觀、喜好與生命背景的繁簡離線翻譯。
- 擴充生物介紹、物品與材料表達、冒險設定／介面／日誌及部分戰鬥用語。
- 擴充傳說人物介紹、日期、親屬、職位、神器、文明事件、節慶與升任紀念故事。
- 修正儀式活動清單含「講述升任故事」時整段仍為英文的缺口，保留外層節慶日期、內層升任日期、人物、職位與其餘活動。
- 修正關閉傳說分頁後，重用原生頁面物件可能帶回舊段落快取的問題。
- 改善持久翻譯快取、歷史紀錄、佇列可見性與增量紀錄讀取；保留原生色彩及連結目標。
- 修正 Windows 測試清理順序：先停止測試 Broker，再移除 SQLite fixture，避免檔案鎖與殘留測試程序。

姓名、地名、作品名等程序生成的專名可能仍以原文顯示。規則只接受已辨識且完整的句型；遇到未知人物／日期／職稱／子句時保留完整原文，避免遺漏資訊或錯接連結。

## 已驗證的發布快照

目標環境：Windows、Dwarf Fortress 53.16、DFHack 53.16-r1.1。包內含 Rust Broker，玩家不需 Node.js。

- Rust workspace 全套測試通過，包含 Broker 119、Native 91 項單元測試及其他工作區套件。
- Node：220 通過、0 失敗、1 項需 live cloud 的 opt-in 測試略過。
- 最終封裝 Native、全新狀態 Broker、實機載入 DLL，各通過 504 項精確繁簡回歸比對（396 接受、108 故意拒絕），AI 提交／請求均為零。這些是開發回歸樣本，**不是遊戲覆蓋率分母**。
- Workshop 結構、914 個 manifest 檔案及全部雜湊、靜態 CRT 依賴、相關 Lua fixture 與 ZIP 915 個檔案均通過檢查。
- 最終包在關閉 AI／雲端下載／投稿、隔離設定與快取的傳說實測中，正確顯示升任故事與 8 個完整節慶段落；點擊 Godseas 打開原生 site 39。
- 原生 687 個段落來源、20,241 個 word records、1,493 個 link records 保持一致。儀式故事實際畫面與節慶畫面穩定觀察為 50 graphics FPS；不代表大型要塞或未暫停效能驗收。
- 正常退出後，10,839 個受保護原始存檔檔案完全一致；玩家設定、AI／舊式快取與 overlay 設定均還原，兩個未改動測試存檔副本已歸檔。

## 待補與驗證邊界

部分道路／橋梁建造、沒有原生連結的角色敘述、程序生成種族、複雜陰謀、動態冒險對話及戰鬥長文仍有缺口。需繼續建立獨立三模式樣本與覆蓋率分母，測量首次顯示、長時間運行及大型人口未暫停效能。此前候選已做小型要塞保存／重載回歸；**最終這組 DLL／Broker 尚未另做完整要塞保存／重載驗收**，本輪完成的是最終包傳說模式實測與原始存檔完整性核對。

更新後請完全退出並重開遊戲，讓新的 DLL 與 Broker 生效。可先關閉 AI，檢查人物文字、物品與傳說頁面的內建中文；仍為英文的段落可留作下一輪補譯樣本。

Steam 沿用既有公共封面及簡介；GitHub 保留原有封面及 Workshop 簡介，更新程式、翻譯資料、驗證文件與 ZIP。
