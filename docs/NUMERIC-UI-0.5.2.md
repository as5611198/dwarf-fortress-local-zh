# 0.5.2：可變數字介面的離線漢化

## 問題與範圍

AI 關閉時，把音效 80% 調成 77%、冒險音樂 85% 調成 84% 或把曲目間隔改成 239 秒，先前中文會變回英文。八個音訊標籤不在本機字典，已知中文來自特定數值的 AI 快取，並非可套用任意數字的固定譯文。

同步盤點原生 Video／Game／Audio 設定的實際繪製文字，以及短數字字典條目：

| 類別 | 發現與處理 |
| --- | --- |
| 主音量、要塞／冒險音樂、環境音、音效、曲目間隔 | 新增八個明確數字模板，首次查找即可離線翻譯 |
| 集會區、臥室數量與 Range 最小／最大值 | 原有 CSV 模板只被當成字面字串；接入數字模板查找 |
| 歷史人物數、編年史事件總數 | 原本只有某個數字的精確條目；新增通用數字模板 |
| 最近地點的旅行天數 | 舊資料枚舉兩天／三天；補上八個方向的可變天數 |
| FPS、人口／種子上限、按鍵延遲、介面縮放 | 標籤與可編輯數字分開繪製，沒有音訊整句查找失效的原因 |
| 年齡、重要擊殺數 | 既有數字規則可處理；繁簡整包測試 21／57／123 均通過 |
| 快捷鍵、解析度、版本、版權、預設值、含名字的歷史敘事 | 不從字面數字自動推測模板，避免誤改識別碼與人名 |

## 實作

原生 DLL 與 Rust broker 共用 `numeric_templates.rs`。字典載入時編譯明確的 `{{count}}`、`{{minimum}}`、`{{maximum}}`、`{{value}}`、`{{year}}`，不接受任意人名或文本擷取。查找採有長度上限的掃描與雜湊索引，不逐幀編譯正則、不讀磁碟、不掃全字典、不為每個新數值留下快取。

保留數字原始字串，支援正負號、小數與合法千分位，並保留顏色前綴。缺漏／重複擷取與歧義模板拒用；若新字典覆蓋成無效模板，舊的已編譯結果也會失效。使用者固定翻譯與精確本機條目優先，數字模板在官方／AI 動態快取之前。

本次修改的是公開包使用的 Rust 執行路徑；歷史 Node broker 未增加此功能。主執行緒一般規則 160 bytes 與背景規則 4096 bytes／25 ms 邊界未變更。

## 驗證與限制

- 原生回歸先重現失敗：首次查找 0% 回傳 `None`；修正後 0／77／78／100% 與含色碼負數、千分位均通過。
- Rust broker 繁簡離線測試：0–100%、舊 AI 快取覆蓋、固定翻譯優先、非法千分位拒收；provider requests = 0，譯文 journal 未增加。
- 整包測試：繁簡模板、房間數量、數值範圍、歷史計數、旅行天數、既有年齡及擊殺規則。
- 遊戲內 AI 關閉：1,632 次繁簡立即查找全部通過。包含七種音量 0–100%、多個間隔／數量／旅行天數，以及負數／小數／千分位／色碼；測試完成恢復繁體。
- 實際音訊畫面原本 77%、239 秒、84% 的英文已變中文；音效滑桿 77% → 59% → 77% 全程中文，畫面顯示 50 FPS，AI 請求數為 0。
- 修正版部署至實際載入的 Roaming 模組目錄與 Steam 本機快取，逐檔驗證 SHA-256；部署前後 154 個玩家狀態檔未改動。原先 Roaming 副本仍標示 0.5.0，因此不能只更新 Workshop 下載目錄。
- 此次沒有開存檔逐頁實測所有數字敘事，不能據此宣稱所有帶數字的任意長文均可離線漢化。年齡／擊殺屬規則層測試；數量模板屬原生查找測試；滑桿有實際 UI 驗證。

本機診斷、測試紀錄與部署備份位於遊戲目錄 `_localization-work/numeric-ui-fix-20261003/`。
