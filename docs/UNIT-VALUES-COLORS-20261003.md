# 人物價值觀顏色遺失修正

## 原因

`df-local-zh-unit-text.lua` 原先移除原文 `[C:fg:bg:bright]` 標記，將整段送入翻譯，然後以英文原有每行第一個顏色替中文行上色。價值觀中文通常比英文短，全部中文可能落在原來的灰色行內，因此個人價值觀與夢想也變灰。原生逐行翻譯與背景整段翻譯使用不同來源文字／快取鍵，所以背景完成時措辭也會改變。

## 修補

- 多色人物段落保留原始標記作為顯示識別，按連續顏色區段取得完整句子的譯文。
- 待所有區段完成後依中文 Unicode 字元換行；使用既有 rich-text alias 保留同一行內的顏色變化。
- 譯文或原生 alias 未準備好、包含未翻譯英文、超出顯示容量時，保留原生顯示，不提交空白或部分譯文。
- 單色段落、需求與暱稱模板沿用既有處理；恢復顯示時保留原始文字和色碼。
- 不改人物價值觀資料或存檔。此修正不承諾首次翻譯等待期間原生逐行措辭與完成後區段措辭完全相同。

## 驗證

- 新增 `self-tests/test-unit-values-colors.lua`，修改前在顏色區段請求斷言失敗；修補後通過。
- 覆蓋灰／亮青／黃跨行、同一行多色、補充平面 Unicode、翻譯等待、原生 alias 等待、縮放換行、重複輪詢與離開頁面還原。
- 既有 `test-unit-sheet-text.lua` 與 `test-display-color-persistence.lua` 通過。
- 實機同一人物價值觀頁恢復三色；切至特質頁再返回仍維持三色，截圖顯示 50 FPS。其後嘗試原始帶色文字的前後自動比對時，玩家已切換至另一人物概況頁（16281 → 16286），故該項實機比對未完成；原始文字不變與還原由上述隔離測試驗證。
- 本機來源、已安裝的兩個 Lua 腳本與 distribution 同步；發布資料夾 validator 通過（847 files），manifest 已更新兩個腳本雜湊。

實機修補與發布驗證分開記錄；0.5.0 修補包包含此修正、百分比辨識與背景長文規則限制更新。上傳與下載回驗結果以發布紀錄為準。
