# 原生中文輸入與功能擴充

本輪使用者已授權 P0–P2 全部功能、必要的遊戲關閉與重啟；禁止子代理。

## 實作邊界

沿用自有 Rust 核心、SDL 輸入橋及 Lua 編輯器。僅借鑑功能概念，不引入 DFCN 原創程式、DLL、SDL 私有位址或其私有 hook。既有第三方資料與字型仍各自保留授權，獨立實作不改變既有資料授權。

## 工作項目

- P0：公開 SDL hint、IMM 定位與取消、公開 TSF 候選 UI sink；分開組字、候選按鍵與查詢提交，退出時釋放回呼。
- P1：設定文字／提示詞草稿與中文命名共用輸入橋，游標按 Unicode 字元邊界；主字型缺字時依序回退，無字型可用時顯示明確替代字元。
- P2：歷史事件由原生事件類型與欄位組成中文，不將人名拆成翻譯碎片；冒險模式新增專用入口／上下文；本機去重漏譯蒐集與字典／規則刷新，不新增預設上傳、不熱換 DLL。

## 驗證與保護

每項以實際生產邏輯的狀態測試、DFHack 控制及啟動／載入驗證。合成 SDL 事件不等同微軟注音候選驗收；OS 實體鍵盤、DPI／全螢幕與實際存檔場景尚未執行者在最後報告列明。

所有部署先驗發布 manifest、確認遊戲停止、備份差異檔案，部署後重驗發布檔及私人設定／名稱／快取／存檔雜湊。驗證資料與備份置於工作目錄的私人驗證區，發布套件不包含它們。

## 已執行的驗證

- Rust workspace：81 通過、8 個原有整合／基準測試預設忽略；另對發布包的真實武器／工具與護甲規則跑 2 個整合測試，全部通過。修正整合測試中過時「十字鎬」用詞及不存在的 great picks 範例，發布資料仍保留既有「鶴嘴鋤」。
- Node 設定／提示詞／設定服務回歸：20 通過，測試資料隔離。
- release 核心與 Broker 編譯成功；包內沿用未變更的已發布 Broker。新 DLL 在部署前獨立 loadlib 驗必要匯出，再關閉遊戲部署。
- 重新啟動的實際安裝核心 enabled=true、顯示版本 0.5.0；51 個發布 Lua 檔案語法可載入；歷史、冒險、診斷、暱稱、設定模組可載入。
- 安裝版 self-tests：UTF-8／補充平面退格、composition 鍵保護、取消、無效提交、提示詞 CRLF／字數上限、金鑰非 ASCII 拒絕、暱稱與提示詞取消、真實歷史事件結構、日誌欄位、去重與覆蓋均通過。
- 遊戲內合成 SDL 測試：多行提示詞組字不改查詢，方向／數字／Enter／Esc／刪除鍵不漏出；commit 正確插入，金鑰選取替換且不公開文字，離開焦點 TSF sink 解除。測試等待 SDL pump／render 邊界，未把固定 UI tick 當作事件處理完成。
- 本機 Windows 字型實際解析及點陣測試；主字型未覆蓋的 U+20000 在安裝版回退索引為 1，𠮷 在主字型覆蓋，U+10FFFF 回傳缺字。選用 Windows 字型未放進包。
- 發布 manifest 825 檔通過，部署後逐檔 SHA256 通過；ZIP 內 825 檔再次逐檔驗 manifest。來源與公開 distribution 已同步。
- 每次替換 DLL 前皆先停止遊戲。自第一次部署前的 5243 個受保護檔案，5240 個雜湊完全相同；3 個運行時快取僅追加，原始完整位元組前綴 SHA256 保留。設定、金鑰、世界名稱、存檔未變更。私人日誌／備份保留在 `_localization-work/ime-validation`，不包含於發布包。

## 尚待玩家一起驗收

1. 真實微軟注音的候選顯示、方向／數字選字、翻頁、提交、Esc 取消與切英文。自動化字鍵表現為直接文字提交，沒有驗到真實候選生命週期；TSF 註冊成功與合成 SDL event 不能替代此驗收。
2. 全螢幕／視窗、100%／125%／150% DPI、64／80 欄下候選定位與視覺缺字，切畫面／失焦時 OS 候選收起。
3. 實際世界的中文暱稱套用及存檔／重讀、歷史分頁與人名、冒險遊玩日誌與原生輸入；目前做的是隔離物件／生產模組狀態測試，未修改玩家存檔。
4. 真實設定草稿跨頁、套用／取消與金鑰欄位 IME 操作；隔離回歸已過，但未改動玩家實際設定以做驗收。
