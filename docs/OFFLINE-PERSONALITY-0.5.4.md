# 0.5.4 人物頁離線翻譯候選版

2026-10-04。本機已安裝並重啟驗證；本次未發布 Steam 或 GitHub。

## 完成範圍

- 原版性格、價值觀、夢想、身心能力、行為習慣及價值衝突使用有界句型組合。
- 喜好段落支援材料、器物、顏色、動物及喜愛原因、食物飲料與厭惡生物。
- 依原版 35 個生物 raw 檔核對 371 個不同 PREFSTRING，全部有獨立編寫的對應詞；另補 8 種植物紙材及坑道管木。
- 以遊戲內真實人物身分及文化作品物件核對名稱邊界。未收錄姓名保留原文；未知曲名等保留在「引號」內，周圍語句仍可翻譯。
- 普通姓名旁的已知職業可獨立漢化，不必等整個姓名翻譯完成。原有暱稱流程保留。
- 與前一階段共計每種語言 16,823 筆離線詞句；這是規則展開後的列數，不代表相同數量的獨立原版句子。

## 實機找出的額外修正

純文字單元測試通過後，實機偏好頁仍未套用整段。原因是一般著色別名拒絕任何英文，連已核對的人名和曲名也被拒絕。

新增專用 literal_colored_key，僅供已驗證身分佔位符還原後使用。別名仍須確認原生字典已載入；快取與普通句子隔離且有上限；不寫入一般文字片段持久快取。未知普通英文仍不能繞過檢查。新增 adapter 整合測試先重現失敗，再修正並驗證。

同時修正 broker 查詢順序：有限規則不得蓋過已校訂內建譯文，例如 Wounds 保留「傷口」。

樣本來自同一世界的 4 位矮人、每人 3 頁、23 段非空文字，繁簡共 46 項。已用這些樣本補詞，所以屬開發回歸樣本，**不能當作獨立盲測或全遊戲 90% 覆蓋證明**。

原生查詢使用不讀 AI／雲端學習快取的 local_lookup；實機另暫時將人物頁強制走此查詢，名稱查詢回傳空值，以確認原文名稱保留路徑。測試後已恢復正常人物頁 adapter。現有學習快取未清除，因此其他未列入測試的 UI 中文不能算離線覆蓋證據。

尚未保證任意生成姓名、作品名稱、概況頁引言、所有需求與事件敘述、冒險模式或其他模組全文離線翻譯。未知語句維持既有回退流程；停用 AI 時可能保留英文。人物頁仍沿用 20-frame 檢查節奏，切頁可能短暫顯示原文，沒有等待模型或湊批次。

## 使用者驗收

1. 在模組設定確認「目前存檔」的 AI 翻譯為關閉；存檔設定優先於全域設定。
2. 開啟居民 → 任選矮人 → 個性，依序看特質、價值觀、偏好。
3. 切換 3–5 位不同角色，再關掉人物視窗重開；檢查文句沒有串人、原版顏色保留、FPS 沒有明顯下降。
4. 若有整段英文、亂碼、顏色錯誤或消失的文字，保留該人物頁畫面供下一批補齊。未知專有名字單獨保留原文是目前預期行為。

## 本機狀態與存檔

原本從 autosave 1 載入；操作「儲存至目前時間線」後，遊戲寫入既有 active save region3，並從 region3 重新載入。備份 autosave 1 已保留。比對兩個 save 根目錄共 10,839 檔，只有 roaming/save/region3/world.sav 因正常存檔改變，沒有新增、遺失或其他存檔異動。

設定未修改：全域 AI=false、autosave 1 覆寫 AI=true；region3 繼承全域 false。API 金鑰、學習快取及其他設定保留。遊戲最後保持暫停。
